ROMANTIC BIRTHDAY WEBSITE V3

1. Edit script.js with Notepad. Change birthdayName, yourName and birthdayMessage.
2. Do NOT double-click script.js. Open index.html in Chrome.
3. Add photos as photos/photo1.jpg through photo6.jpg.
4. Add your MP3 as music/birthday-song.mp3.
5. Add your MP4 as video/birthday-video.mp4.
6. Upload the entire folder to GitHub Pages to get a shareable phone-friendly link.
